# CAD files

This folder collects the project’s native design files and print exports.

- `Blender/` — Blender leg source model and related STL meshes.
- `3D Print V1/`, `3D Print V2/`, `3D Print V3/` — versioned STL exports; V2 also includes the Fusion bevel model and base DXF drawings.

STL files are manufacturing exports. Editable sources are the `.blend` leg model and `.f3d` bevel model where provided. The full final six-leg assembly is represented by the CAD screenshot in `docs/images/`; a matching editable assembly file was not present in the source folder. Inspect dimensions and fit against the current assembly before printing.
